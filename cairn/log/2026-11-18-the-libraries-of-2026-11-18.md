# The libraries of 2026-11-18

Comodoro moved onto pimalaya-cli 0.6.1 (from 0.5.2) and pimalaya-config 0.6.0, released on 2026-11-18, with no [patch]. No Comodoro code changed: it uses no `Listing`, the breaking change of pimalaya-cli 0.6.0, sets no `allow_missing_positional` on an MCP tool, which `Grammar::new` now refuses, and never matches `SecretError::Output`, the breaking change of pimalaya-config 0.6.0.

## What reaches users

- A value filled into a hook notification is escaped where the daemon reads markup, its line breaks and tabs turned into spaces, its other control and bidi override characters dropped (`NotificationTemplate::render`), so a cycle name a server sends cannot style or reshape the notification.
- The text error report sanitizes its message and each cause line by line.
- `--log-file` creates the file at 0600 and refuses a symbolic link at its path.
- The manual pages print the version once in their VERSION section.
- A TOML parse error of the configuration no longer prints the source line, and a refused secret no longer echoes its value; a secret command that fails is named, with a hint to run it yourself.

## Capabilities moved

hooks: a filled notification value is escaped as pimalaya-config renders it.

## Verified

`cargo test --all-features` and `cargo clippy --all-features --all-targets` pass; `comodoro mcp` starts and lists its tools.
