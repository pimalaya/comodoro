# The CLI alignment round

Comodoro's line of the family's CLI alignment round (M1, owner ruling D6). A hook reads `cmd` as the alias of `command` again (`#[serde(alias = "cmd")]` on `TimerHook::command`, src/cli/hook.rs), as pimalaya-config states it wherever a command is configured: `CmdRenamedConfig`, which refused it naming `command`, is gone.

Comodoro moves to pimalaya-cli 0.5.2 (the Cargo.lock diff is that crate alone, the requirement raised to `0.5.2`). The kit refuses a nested `repl` or `mcp` line, by name, alias or prefix, coded `usage-invalid` where Comodoro's own refusal carried no code; a `-V` or `--version` line prints the version `Command` now carries (`#[command(version, long_version = long_version!())]`); a refused MCP call names its argument through `tool.grammar.usage_error(&err)` (``Invalid value `-1` for `seconds`: invalid digit found in string``), where it read clap's text.

The nested-session arm sat in `Command::run`, which matched every command for the REPL and MCP lines, so it could not be dropped while `run` existed: `Command::execute` now runs over a `Session` (src/cli.rs; the configuration paths, the account name and the account once taken), the shape of Ortie, Himalaya and Cardamum, and the REPL, the MCP server and main all go through it. In the library, `Command::execute` takes the `Session` and `Command::run` is gone.

Tests, each failing before the change: tests/config.rs `the_cmd_hook_key_reads_as_command` (through the binary, replacing `the_cmd_hook_key_of_v1_is_refused_by_name`), tests/hook.rs `a_cmd_key_runs_as_the_command`, tests/repl.rs `a_version_line_prints_the_version` and the `usage-invalid` code in `sessions_and_commands_running_until_interrupted_are_refused`, tests/mcp.rs on the family wording.

Capabilities moved: hooks ("A hook runs a command, shows a notification, or both", "A removed hook spelling is refused by name"), config ("Unknown keys are refused at every level"), repl ("A session runs the CLI over one account", "Help keeps JSON lines whole"), mcp ("A tool's input is the command's grammar").
